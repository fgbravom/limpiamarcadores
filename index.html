Cómo exportar tus marcadores
  1. Chrome, Brave, Opera, Vivaldi: administrador de marcadores (Ctrl+Shift+O) → menú ⋮ → Exportar marcadores.
  2. Edge: favoritos (Ctrl+Shift+O) → menú ⋯ → Exportar favoritos.
  3. Firefox: biblioteca (Ctrl+Shift+O) → Importar y respaldar → Exportar marcadores a HTML.
  4. Safari: Archivo → Exportar → Marcadores.

Cómo volver a importar el resultado
  1. Guarda tu archivo original como respaldo. No se modifica.
  2. Descarga el archivo limpio con el botón de abajo.
  3. Abre el administrador de marcadores de tu navegador (Ctrl+Shift+O), selecciona todo (Ctrl+A) y elimina los marcadores actuales. Si no, el navegador suma los importados a los que ya tienes y vuelven los duplicados.
  4. Importa el archivo descargado desde la opción Importar marcadores → «Archivo HTML». En Safari es Archivo → Importar desde → Archivo HTML de marcadores.
  5. Algunos navegadores dejan los marcadores importados dentro de una carpeta nueva (por ejemplo «Importado»). Mueve su contenido donde quieras.

Al fundir, todo el contenido de las carpetas marcadas pasa a la carpeta destino y las demás desaparecen. Si adentro hay subcarpetas con el mismo nombre, también se funden. Nombres como «Imágenes» e «imagenes» cuentan como iguales.
